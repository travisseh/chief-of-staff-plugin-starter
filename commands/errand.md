# Virtual Errand

Use browser automation for errands that need a real website.

## Before Starting

1. Read `skills/errands/SKILL.md`.
2. Check what browser or automation tools are available.

## Safety

- Never place an order without showing the total and getting approval.
- Never enter payment credentials manually.
- Pause before sending messages, booking appointments, or committing the user to something.

## After Completing

Record the outcome in `state/daily/YYYY-MM-DD.md` if a daily note exists.
