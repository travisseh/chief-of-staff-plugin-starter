# LinkedIn Setup

## What You Need

- A browser automation tool connected to Claude Code
- An active logged-in LinkedIn browser session

## Credentials

No separate API key is required in this starter.

## Expected Workflow

1. Open LinkedIn messaging.
2. Read the conversation list.
3. Open the relevant thread.
4. Draft a reply.
5. Pause for approval before sending.

## Notes

- This is intentionally browser-session based.
- If LinkedIn asks for login or extra verification, pause and ask the user to complete it.
- Use [writing-style](../../skills/writing-style/SKILL.md) for DMs and [linkedin-voice](../../skills/linkedin-voice/SKILL.md) for posts or comments.
